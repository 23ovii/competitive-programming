# Codeforces Solutions

This folder contains solutions to Codeforces competitive programming problems.

## Directory Structure

### Live Contest Rounds
Folders with contest round names contain solutions to contests taken live:
- **Codeforces Round 1077** - Problems solved during live contest
  - 2188A.cpp
  - 2188B.cpp
  
- **Codeforces Round 1080** - Problems solved during live contest

- **Codeforces Round 1091** - Problems solved during live contest

- **Codeforces Round 1096** - Problems solved during live contest

- and many more to come

### Problem Set
The `problemset` folder contains solutions to Codeforces problems solved outside of contests:
- 1A.cpp through 1091A.cpp and beyond
- These are individual problems solved for practice and learning

## Problem Naming Convention

Files are named according to the Codeforces problem identifiers (e.g., `1A.cpp` refers to problem 1A, `2188B.cpp` refers to problem 2188B from a specific contest).

## File Format

All solutions are written in C++ (`.cpp` files).
